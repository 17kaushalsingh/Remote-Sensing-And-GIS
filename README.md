# Remote Sensing and GIS

Jupyter notebooks and reports for a Remote Sensing & GIS course, covering spatial analysis, satellite imagery, raster/vector data processing, and geospatial visualization using Python.

## Assignments

| Assignment | Topics |
|------------|--------|
| [Assignment 1](Assignment1/) | Introduction to GIS — spatial data fundamentals |
| [Assignment 2](Assignment2/) | Vector analysis and distance calculations |
| [Assignment 3](Assignment3/) | Raster analysis, mountain elevations, and spatial queries |
| [Assignment 4](Assignment4/) | Satellite imagery, population analysis, crime mapping, and contour generation |

## Tools & Libraries

- **Python**: `geopandas`, `rasterio`, `folium`, `matplotlib`, `numpy`, `pandas`
- **Platform**: Jupyter Notebooks
- **Data formats**: Shapefile (`.shp`), GeoTIFF (`.tif`), CSV, SRTM elevation (`.hgt`)
